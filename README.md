## ▶️ Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Thuliofj/Logica_python_ad05.git
   ```

2. Entre na pasta do exercício que quiser testar:

   ```bash
   cd Logica_python_ad05/06_Fizzbuzz
   ```

3. Execute o arquivo Python:

   ```bash
   python nome_do_arquivo.py
   ```

> Substitua `nome_do_arquivo.py` pelo nome do arquivo dentro da pasta escolhida.
